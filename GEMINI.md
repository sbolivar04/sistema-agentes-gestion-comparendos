# Directrices del Proyecto

1. **Idioma del Código**: Todo el código nuevo o modificado (archivos, carpetas, funciones, variables, clases, modelos y comentarios) debe estar nombrado en **español**.
2. **Base de Datos**: Se utiliza **Supabase Cloud (PostgreSQL)** en el esquema `comparendos_fscr`.
3. **Flujo de Trabajo**: Avanzar fase por fase con validación previa del usuario.
